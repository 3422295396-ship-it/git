# 实际验收记录

验收日期：2026-10-07。交付物为纯 HTML / CSS / JavaScript 静态项目，正式运行不需要测试工具或 Node.js。

## 测试环境

- Windows 上的 Microsoft Edge / Chromium，Playwright 自动操作，包含真实 `file://` 项目加载与浏览器网络离线模式。
- WebKit 浏览器引擎，iPad 第 7 代横屏的尺寸、触摸和浏览器参数模拟；使用本地 HTTP 服务，阻断所有外部网络请求。
- 本地 HTTP 的 Service Worker 缓存测试：首次缓存全部资源后关闭网络，刷新并继续抽卡、揭晓图片。
- 无 DOM 的规则引擎测试，验证跨模式共享卡池及每次挑战只能记录一个结果。

## 验证范围与现场使用

本次完成了浏览器功能验收与平板尺寸 / 触摸模拟，没有使用实体 iPad 或安卓平板进行实机验收。Windows WebKit 对本地文件来源和原生离线开关的测试出现浏览器内部错误，因此其触摸验收改用本地 HTTP 并阻断外部请求；完整本地文件断网与缓存后的离线刷新由 Chromium 实际验证。

iPad 请用 Safari 打开静态托管地址或本地 HTTP 地址，“文件”App 的 HTML 快速预览不能作为完整游戏运行环境。HTTPS 托管时先确认页脚「离线已就绪」，再断网使用。普通局域网 HTTP 时需保持本地服务可访问，互联网连接可以关闭。

全屏采用浏览器能力检测，不支持时仍可正常游戏。可选 WebMCP 接口也做了能力检测；验收浏览器没有提供该接口，本次未验证真实 WebMCP 调用，主游戏不依赖它。
