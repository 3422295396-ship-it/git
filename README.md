# 动漫社 · 二次元抽卡挑战

纯前端招新摊位小游戏：204 张固定题、5 种模式、23 个作品系列、83 个角色图条目。所有 96 张固定动作卡都有原作角色图片，36 张看图题均使用独立角色的局部图与答案图。无限挑战每轮有 1324 种本地组合任务，其中 668 道动作题也有角色参考图。

## 直接运行

解压完整项目，在支持本地网页的电脑浏览器中打开 `anime-club-game/index.html`。不需要安装依赖或构建。保持 `assets` 文件夹和脚本与 HTML 的相对目录结构；不能只复制 HTML 文件。

平板推荐使用 HTTPS 静态托管链接，Safari 或其他正常浏览器直接打开即可。iPad“文件”App 的 HTML 快速预览不等同于完整网页运行环境。首次打开托管地址需联网，等页脚显示「离线已就绪」后即可断网继续游戏和刷新；清理站点数据或系统回收缓存后需要重新联网缓存。

电脑本地预览也可在项目目录运行 `python -m http.server 8080`，访问 `http://localhost:8080`。普通局域网 HTTP 的平板访问需要保持电脑静态服务可用，浏览器通常不会为这种地址启用 Service Worker。

## 玩法

| 模式 | 内容 | 数量 |
| --- | --- | --- |
| 动作模仿 | 原作角色图、角色名、动作任务；点击图片查看大图 | 96 张 |
| 看图挑战 | 先看局部猜角色，点击「显示答案」揭晓角色及作品 | 36 张 |
| 速画快答 | 短时绘画、口头快答 | 72 张 |
| 随机混抽 | 三类共用固定卡池 | 204 张 |
| 无限挑战 | 本地组合生成，轮内不重复，用完自动续轮 | 每轮 1324 种 |

动作图是**角色外观参考**，具体动作按题目文字演出。自由题显示「参考示例」，可以换成熟悉的角色；宝可梦训练家投球题显示「伙伴示例」。图片按钮支持触摸，大图可点右上角 × 或按 Esc 关闭。

看图题的标题、替代文本和最近记录在揭晓前不显示答案。每一道新题对应一个新角色，并非重复同一角色的不同裁切。

**覆盖作品：** 《咒术回战》、《鬼灭之刃》、《间谍过家家》、《火影忍者》、《原神》、《崩坏：星穹铁道》、《绝区零》、《王者荣耀》、《第五人格》、《海贼王》、《宝可梦》、《龙珠》、《碧蓝航线》、《崩坏3》、《名侦探柯南》、《死神 BLEACH》、《孤独摇滚！》、《刀剑神域》、《Re：从零开始的异世界生活》、《魔法少女小圆》、《初音未来 / Piapro》、《星之卡比》、《索尼克》。

无限挑战组合为：83 个角色 ×（8 种动作 + 6 种速画）+ 23 个作品 × 6 种快答 + 24 道自由题 = 1324。这里“无限”指自动开始下一轮；组合总数有限，进入下一轮可能遇到之前轮次的任务。两轮边界避免连续出现相同一题。

- 默认不重复；抽出时消耗固定卡片，各固定模式与混抽共用去重进度。
- 「允许重复抽题」仅影响固定题库，重复时不消耗之前的去重进度。关闭后接着原来的一轮。
- 无限模式的轮次与固定卡池独立；返回固定模式不会恢复已用卡。无限模式暂时禁用重复开关。
- 重置卡池会恢复 204 张固定题、重启组合轮次、清空当前挑战及最近抽卡、停止计时；保留今日参与和成功 / 失败统计。
- 成功抽卡时参与次数加一，工作人员每张只可记一次结果。未判定就下一张时仍计参与，不虚增成功或失败。
- 倒计时支持 10 / 15 / 30 秒，手动开始、暂停、继续、重置；切后台返回时校正真实经过时间。
- 音效默认关闭，抽卡连点有锁定保护；最近记录展示 6 张。刷新页面会重置本次数据。

## GitHub Pages 部署

交付的 `github-pages-game.zip` 为**根目录上传包**：解压后把所有文件及 `assets` 文件夹一起上传到仓库根目录，保证仓库根目录直接存在 `index.html`。然后 Settings → Pages → Deploy from a branch → 选择实际分支及 `/ (root)` → Save。

必须以 Pages 设置页的发布成功状态和链接为准。项目支持仓库子路径，所有资源使用相对 URL，不需要自定义域名、服务器或数据库。Cloudflare 拦截旧链接的网络问题不会因修改游戏代码而自动消失；使用 GitHub Pages 时会使用新网址。

## 文件结构

```text
anime-club-game/
├── index.html             # 页面、图标、大图对话框
├── style.css              # 布局、触摸、横竖屏样式
├── app.js                 # 展示、计时、音效、事件
├── engine.js              # 固定池、组合池、单次判定
├── cards.js               # 原有 36 张题，内容保留
├── extra-cards.js         # 60 动作 + 60 快答，12 个基础作品
├── visual-cards.js        # 角色图映射、24 新动作、24 新看图题、11 个新作品
├── generator.js           # 1324 种本地组合任务
├── asset-manifest.js      # 119 张本地 JPEG 的缓存路径
├── sw.js                  # HTTPS / localhost 离线缓存，版本 v3
├── README.md
├── TEST-REPORT.md
└── assets/
    ├── SOURCES.md          # 所有来源页面和原图链接
    ├── sources.json        # 原有 12 道看图题的来源及裁切
    ├── visual-sources.json # 83 个角色条目，新图裁切及 SHA256
    ├── images/            # I01～I36_guess；I01～I12_answer
    └── characters/        # 新增 71 张参考图，新看图答案复用对应参考图
```

共有 119 张 JPEG：原有 24 张 + 71 张新角色图 + 24 张新猜题图。83 个角色图条目包含原有 12 张答案图。新看图题复用相同角色参考图作为答案，节省下载和缓存空间。

没有在线字体、CDN 或远程图片依赖；不使用 ES Module、运行时在线 API、AI 服务或业务后端。图片、脚本、样式均保存在项目中，直接文件加载时不依赖 Service Worker。

## 维护题库与图片

原有题目在 `cards.js`，基础扩展题在 `extra-cards.js`，本次新增题及角色图对应关系在 `visual-cards.js`。`reference` 含 `key`、`name`、`source`、`image`；自由题增加 `example:true`。生成动作根据角色名与作品同时匹配图片，避免同名孙悟空在《龙珠》与《王者荣耀》之间混淆。

固定题编号为 A01～A96、I01～I36、Q01～Q72。手动增加请从 A97、I37 或 Q73 起，并确保全局唯一。剩余数量及卡池进度根据实际数据自动计算。增加作品或角色后，组合生成数量也会自动计算，同步更新本说明和 HTML 初始数字即可。

看图题包含 `guess` 与 `answer` 两个本地路径。制作 guess 时，保留服装、发饰、武器等辨识细节，避开完整面部及角色名。当前猜题图 960×540，裁切后按比例放入画布；答案保留原作比例，图片框使用 contain，避免二次裁切。新增参考图最长边不超过 1100 像素。

增加、更名或删除图片后，同步更新 `asset-manifest.js` 中的 `GAME_ASSET_FILES`。更新在线版本时递增 `sw.js` 缓存版本；重新打开后确认离线就绪。发布包需要包括所有新增脚本与图片。

## 素材与验证范围

所有角色图均取自原作形象，使用动画 / 游戏官网、官方社区或收录原作素材的资料站；没有生成替代角色图。来源记录明确区分官网与社区资料站，原始下载和本地处理后的 SHA256 均保留。角色素材权利归原作者及权利方。

浏览器与触摸模拟测试记录见 `TEST-REPORT.md`。已检查平板常见横竖屏尺寸；模拟测试不等同于用户实体平板和其公网网络的实机验收。
